# Project Context

## Proyecto

Salón y Barbería Yaris será un sistema web para administrar la operación del salón y ofrecer una experiencia pública para clientes.

## Problema que resuelve

El sistema centralizará la gestión de servicios, profesionales, horarios, citas, contenido público y, posteriormente, catálogo y comercio electrónico. La disponibilidad debe ser confiable y las decisiones operativas deben quedar registradas.

## Actores

- Yaris: administradora principal del sistema.
- Futuros administradores: sujetos a autorización futura.
- Profesionales: recursos operativos, no usuarios administrativos.
- Clientes: personas que solicitan citas o realizan compras sin necesitar una cuenta en V1.

## Módulos previstos

- Gobernanza y configuración base.
- Núcleo del negocio.
- Motor de citas y disponibilidad.
- Agenda administrativa.
- Reserva pública.
- Motor de notificaciones y WhatsApp.
- CMS estructurado para contenido público.
- Catálogo, inventario, carrito, checkout y pedidos.
- Reviews, favoritos, seguridad, auditoría, accesibilidad, SEO y operación.

## V1 y V2

El alcance exacto se congela en `MASTER_TECHNICAL_SPEC.md` y en cada SPEC. La prioridad inicial es gobernanza, foundation, business core y appointment engine. Integraciones externas, pagos reales y cualquier capacidad no aprobada expresamente permanecen fuera de alcance.

## Información pendiente

Continúan pendientes de confirmación: datos definitivos del negocio, profesionales, servicios, precios, imágenes, textos, políticas, proveedor de hosting, proveedor Meta y reglas operativas que no estén documentadas en `BUSINESS_CONTEXT.md`.
